# Dysphagia in Older People (UK)

This repository contains a simple Python script and a written report explaining
dysphagia (swallowing difficulties) in older adults in the United Kingdom.

## 📌 Project Purpose
The aim of this project is to:
- Demonstrate how Python can model dysphagia risk factors.
- Provide clear educational information about dysphagia in older people.
- Support learning for healthcare, nursing, and care assistant practice.
- Build a portfolio project combining health knowledge and coding skills.

## 🧠 What is Dysphagia?
Dysphagia is difficulty swallowing. It is common in older adults, especially those
with stroke, dementia, frailty, or neurological conditions. It can lead to:
- Aspiration pneumonia  
- Malnutrition  
- Dehydration  
- Reduced quality of life  

This project explains these issues in a simple, structured way.

## 🐍 Python Script
The file `dysphagia_analysis.py` includes:
- A small dataset of example patients  
- A risk scoring function  
- A risk classification system (high, moderate, low)  
- Printed output showing each patient's risk level  

This script is **educational only** and not clinical software.
